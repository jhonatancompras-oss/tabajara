# Dicionário de português do Brasil

Os arquivos de dados `pt_BR.aff` e `pt_BR.dic` são do projeto VERO, de
Raimundo Santos Moura e colaboradores, distribuídos sem modificações.
Foram obtidos de `LibreOffice/dictionaries`, revisão
`67032ee957631908098a72edf48dc81cac27e369`, pasta `pt_BR`.

Os avisos e as condições originais estão em `pt-BR/README_pt_BR.txt`,
`pt-BR/README_en.txt` e no cabeçalho de `pt_BR.aff`. Os textos das licenças
Mozilla Public License e GNU LGPL/GPL acompanham os arquivos. Trata-se de
dados lidos em tempo de execução; não foi incorporado código do LibreOffice.

O instalador coloca o dicionário em `%LOCALAPPDATA%\Word Tab\dictionaries`,
um local já suportado pelo Word Tab. Preserva arquivos existentes e os dados
do usuário durante a desinstalação. `SHA256SUMS.txt` permite verificar todos
os arquivos incluídos.
